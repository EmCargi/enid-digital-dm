# Global Alliance

**Leader:** Chairman General (Akronia-led military pact)
**Stronghold:** Republic of Akronia + surviving nation-states
**Doctrine:** Anti-psi, tank superiority, Project Butterfly orbital lasers
**Recruitment:** "Normal humans" vs LOA "psiocracy"

The Alliance sells normalcy. Underneath, it runs the same psychic program it denounces — kidnapped psychics locked in psycho-pods, powering the same mecha it calls LOA's abomination.

**Forces:** Modern tanks/APCs (numerical edge), psycho-slave mecha (enslaved psychic + command pilot), orbital laser net (incomplete).

**Current war:** Tavarre (3+ years, stalemate, sporadic ceasefires). LOA's psycho-frames erased the tank advantage; the Alliance's lasers are the next escalation.
